# 12 加速度のある合成（速さが変わる場合）

## 1. ねらい

水平投射を「水平方向の等速運動」と「鉛直方向の等加速度運動」の**合成**として捉えさせる。教科書では答え（放物線）を先に見ることが多く、合成で放物線になる過程を見る機会が少ないため。

- 一方が等速、他方が初速度 0 の等加速度 → **放物線**（水平投射と同じ形）
- 両方が初速度 0 の等加速度 → **直線**（変位の比 x : y が時間によらず一定）
- 船が加速するとき、**水に対する跡はまっすぐ、地面に対する跡は放物線**。「走る電車の中で落としたボールは、車内から見るとまっすぐ落ち、外から見ると放物線」と同じ構図。
- 流れが加速しても、**向こう岸まで渡る時間は変わらない**（成分の独立性）。

## 2. 記号

| 記号 | 意味 | 単位 |
|---|---|---|
| a₁ | 物体の、媒質に対する加速度 | m/s² |
| a₂ | 媒質（流れ）の加速度 | m/s² |
| a | 合成加速度（地面に対する）。a = a₁ + a₂ | m/s² |

- v₁・v₂ は **t = 0 での速度**（初速度）として扱う。時刻 t での速度は v₁ + a₁t、v₂ + a₂t、v + at。
- a₂ は流れと同じ軸に限る（流れは上下左右のどれかのまま）。符号は正負どちらもよい（流れが弱まる場合も表せる）。流れの軸が変わったら a₂ は 0 に戻す。
- 成分は整数（m/s²）。

## 3. 入口（選択肢を増やさない）

ヘッダーの「例」に1グループ足す。① の操作ボタンは増やさない。

| まとまり | 例の名前 | v₁ | a₁ | v₂ | a₂ | 止め方 | 起きること |
|---|---|---|---|---|---|---|---|
| 速さが変わる | 船だけだんだん速くなる | (0, 0) | (0, 2) | (3, 0) | (0, 0) | 向こう岸で | 放物線。水に対してはまっすぐ |
| 速さが変わる | 流れだけだんだん速くなる | (0, 4) | (0, 0) | (0, 0) | (1, 0) | 向こう岸で | 向きの違う放物線 |
| 速さが変わる | 船も流れも止まった状態から速くなる | (0, 0) | (0, 2) | (0, 0) | (1, 0) | 向こう岸で | 直線 |

- 例の名前に「放物線」「直線」は入れない（予想する前に答えを見せないため）。
- この3つを選ぶと「加速度を使う」状態になり、③に加速度の行が出る。ほかの例を選ぶと加速度は 0 に戻り、行も消える。
- 加速度を使う状態のまま、③の数値や流れの操作で自由に変えてよい。

## 4. 表示

### ① イメージ図

- 物体から出る矢印は、**その時刻の速度**（v₁ + a₁t など）。v の矢印は地面に対する跡の接線の向きになる。
- 1秒ごとの点の間隔が変わっていく（ストロボ写真と同じ見え方）。
- 水に対する跡（青い点線）は r₁ = v₁t + ½a₁t²、媒質シートの移動は v₂t + ½a₂t²。

### ② ベクトル図

- 速度の矢印は、**その時刻の速度**を描く。見出しに「t = 1.5 s の速度」と添える。
- 加速度 a₁・a₂・a を、速度と同じつなぎ方（a₁ を原点から、a₂ を a₁ の先から、a を原点から）で**点線**で重ねて描く。ラベルは「a₁ = 2.0 m/s²」。
- a は v と同じく、再生が終わるまで出さない（[06_modes-and-sync.md](06_modes-and-sync.md)「合成速度 v を出すタイミング」）。
- 方眼の範囲は、再生の最後の速度まで収まるように決める（再生中に縮尺が変わらないように）。

### ③ 成分表

- 速度の3行の下に、加速度の3行（a₁、＋a₂、a）を同じ形で足す。a の行は v と同じく、出すまで「？」。
- a₂ は流れの軸の成分だけを入力できる（もう一方は 0 のまま）。
- 加速度を使う状態のときは、表の上に「速度は t = 0 のときの値」と添える。

### つまみ（ドラッグ）

- 加速度を使う状態で t > 0 のときは、①② のつまみを出さない（矢印はその時刻の速度なので、つかんでも初速度を変えられないため）。「最初へ」で t = 0 に戻ると出る。

## 5. 終了条件

等速のとき（[03_scene-view.md](03_scene-view.md) §3）と同じ条件を、等加速度の式で厳密に求める。各成分 p(t) = p₀ + ut + ½ct² が岸・画面の端に達する時刻は、2次方程式の最小の正の解。

- 向こう岸に着いたら止める。
- 加速度のために**元の岸に戻ってきたら**止めて、「元の岸に戻ってきた」と表示する。
- 出発の時点で向こう岸へ向かう速度が負、または速度が 0 で加速度が負なら出発しない。

## 6. 渡った記録

- 加速度を使った回が1件でもあれば、記録の表に「船 a₁」「流れ a₂」の列を足す。
- 渡る時間は、横断方向の v₁ と a₁ だけで決まり、流れ（v₂、a₂）には関係しない。流れの加速度を変えて渡り直すと、時間がそろう。
