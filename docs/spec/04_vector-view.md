# 04 ② ベクトル図ビュー

方眼の上で v₁・v₂・v の矢印を作図する。

## 1. 方眼

- 1マス＝1 m/s。原点（作図の始点）に印を付ける。
- 表示範囲は既定で −8〜+8（各軸）。問題データで変更できる（段階4で 5-12-13 を使う場合など）。
- 軸の目盛り数字は5ごとに表示。

## 2. 矢印の置き方

1. 下部の「v₁」「v₂」「v」ボタンのどれかを押す（色付き）。
2. 方眼上で**始点を押し、終点で離す**。始点・終点とも格子点にスナップする。
3. 置いた矢印は、
   - 終点のハンドルをドラッグ → 向きと大きさを変える
   - 矢印の胴体をドラッグ → 平行移動（向き・大きさは変わらない）
4. 「1つ戻す」「全部消す」ボタンを持つ。

- 置ける矢印は各記号1本ずつ。
- 問題で与えられた矢印は固定表示（ハンドルなし、少し薄い色）にする。

## 3. 作図の約束（判定の対象）

正しい作図は次のいずれか。

- **つなぐ方式（既定）**：v₁ の始点を原点に置き、v₁ の終点に v₂ の始点をつなぎ、原点から v₂ の終点へ v を引く。v₂ を先に置いて v₁ をつないでもよい。
- **平行四辺形方式**：v₁ と v₂ の始点をともに原点に置き、原点から対角の頂点へ v を引く。

どちらの方式も正答とする。判定の詳細と、つなぎ方を誤ったとき（例：始点同士をそろえて先端どうしを結ぶ）の診断は [09_judging-and-feedback.md](09_judging-and-feedback.md)。

## 4. 補助表示（ON/OFF）

| 補助 | 内容 | 既定 |
|---|---|---|
| 大きさ表示 | 矢印の記号に大きさを添えて「v₁ = 4.0 m/s」と図の中に書く（小数第1位）。① イメージ図でも同じ | 探究ON／練習OFF |
| 成分の点線 | 各矢印の x 成分・y 成分を点線で示し、点線の横に成分の値（例：−1、3）を添える | 段階3以降でON |
| 平行四辺形 | つなぐ方式で描いたとき、もう一方の並べ方を薄く重ねる | 照合時のみ |

## 5. 同一直線上の場合

v₁ と v₂ が同一直線上（段階1）だと、つないだ矢印が重なって見えなくなる。v₂ = 0 のときも v と v₁ が重なる。このときは v₂ を直線の片側に、v を反対側に 0.35 マスずらして描く（成分の値は変わらない）。

### ラベル（「v₁ = 4.0 m/s」など）の位置

ラベルは、**矢印・つまみ・原点・ほかのラベルと重ならず、図からはみ出さない位置**を、候補の中から順に探して置く（`src/views/common/labelLayout.ts`）。

1. 矢印の横（中点 → 少し端寄り）。先に試す側は、三角形なら外側、同一直線上ならずらした側。
2. 反対側、さらに1段外側。
3. 先端の先（つまみをよける距離をとる）。
4. どこも空いていなければ、図に収まる最初の候補。

置く順は v → v₁ → v₂ → 成分の値。v を一番よい場所に置く。

## 6. イメージ図との対応

- ② の v₁ の向きは、① の船首の向きと常に一致させる（探究モード、および練習モードの照合時）。
- 再生中は ② の v（赤）の向きと、① の地面に対する軌跡の向きが同じであることが分かるよう、v を軽く明滅させる（v を出しているときだけ）。
- 探究モードで v を隠している間は、v₁ と v₂ をどちらも原点から描く。v を出すときに v₂ が v₁ の先端まで滑る動きが、「つなぐ」作図そのものを見せる（[06_modes-and-sync.md](06_modes-and-sync.md)「合成速度 v を出すタイミング」）。
