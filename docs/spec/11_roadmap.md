# 11 開発ロードマップ

各フェーズの終わりに、授業で使える状態になっていることを目標にする。

## フェーズ1：探究モードの土台（教師の提示で使える）

- 3窓の画面構成（PC・タブレット横／スマホ縦のタブ切替）
- 探究モード：v₁・v₂ の状態と、①②③からの操作・自動連動
- ① イメージ図：川と船スキン、媒質シートと浮遊物、2本の軌跡、ストロボ点
- 連続再生（×1／×2、一時停止、リセット）、対岸到達・時間指定の終了条件
- 提示モード（拡大表示）
- `model/` の単体テスト

**完了の目安**：段階1・2の場面を教師が自由に作って再生し、「向けた方向≠進む方向」を提示できる。

**状況**：実装済み（2026-10-24）。「例」から6つの典型的な状況を呼び出せる。イメージ図でも v₂ をドラッグで変えられる。合成速度 v は再生が終わってから出す（「v を表示」で先に出すこともできる）。

## フェーズ2：練習モードと「足す理由」（生徒が各自で使える）

- 練習モード：予想 → 構成 → 答え合わせ → 再生 → 照合 → 振り返り
- 問題型 T1〜T3、段階1〜3の収録問題、類題の自動生成
- 作図・成分表の判定、誤答診断 D1〜D6、ミニ問い（渡る時間）
- コマ送り再生（コマの長さ切替を含む）
- 比較表示（流れなしの物体）
- 学習記録と記録カード

**完了の目安**：生徒が段階1〜3を1時間で解き進め、記録カードを提出できる。

## フェーズ3：発展と広がり

- 段階4（逆算、T4）と円のガイド
- スキン追加（風と飛行機、動く歩道と人）
- 媒質視点（カメラが媒質と一緒に動く）
- URL パラメータでの状態指定

## 未決事項（実装しながら決める）

- 色の具体的な値（色覚の多様性に配慮した配色の確認）
- コマ送りの各段階のアニメーション時間（0.6 秒は仮）
- イメージ図上の速度矢印の倍率
- 浮遊物の数と見た目
