# 01 学習設計

## 1. 用語と記号

教科書の表記にそろえる。画面上の表示も同じ記号を使う。

| 記号 | 意味 | 画面での呼び方 |
|---|---|---|
| **v₁** | 媒質に対する物体の速度 | 「物体の速度（水に対して）」※媒質名はスキンで変わる |
| **v₂** | 媒質の速度（地面に対する） | 「流れの速度」 |
| **v** | 合成速度（地面に対する物体の速度） | 「合成速度（地面に対して）」 |

- 関係式：**v = v₁ + v₂**、成分では vx = v₁x + v₂x、vy = v₁y + v₂y。
- 単位は m/s のみ。方眼1マス＝1 m/s。
- 座標：x は右向き正、y は上向き正（画面上方向）。

## 2. 想定するつまずき

| ID | つまずき | よく出る誤答 | 主に効く仕掛け |
|---|---|---|---|
| M1 | 向けた方向に進むと思う | 着岸点を真向かいに予想する | 予想→再生→照合、2本の軌跡 |
| M2 | 媒質に対する速度と地面に対する速度を区別しない | 合成速度に v₁ をそのまま書く | 媒質に対する軌跡（シートと一緒に流れる線）、媒質視点 |
| M3 | ベクトルを足す理由がわからない | 作図の手順を覚えているだけ | コマ送り再生（変位の足し算） |
| M4 | 引いてしまう／つなぎ方を誤る | 始点同士をそろえて先端を結ぶ（v₁ − v₂ になる） | 作図手順の判定と診断メッセージ |
| M5 | 流れがあると渡る時間が延びると思う | 「流されるぶん遅く着く」 | 流れなしの船との同時比較 |

M4・M1 などの誤答パターンの判定と、それぞれへの返し方は [09_judging-and-feedback.md](09_judging-and-feedback.md) に定める。

## 3. 1問の学習サイクル（予想 → 構成 → 再生 → 照合 → 振り返り）

練習モードの1問は次の順で進む。

1. **予想**：①で着岸点（または到達点）をタップする。経路を指でなぞる予想描きも任意で可。
2. **構成**：問題で欠けている表現（②の作図、③の数値）を作る。
3. **再生**：アニメーションを再生する。予想マーカーは残したまま。
4. **照合**：予想と結果のズレ、作図と正答の一致を表示する。
5. **振り返り**：ズレがあった場合、つまずきIDに応じた短い問いかけを出す（答えを言い切らず、見るべき所を指す）。

予想を先に置くのは、**予想が外れた経験が概念変化の起点になる**ため。予想を省略して再生できないようにする（探究モードではこの制限はない）。

## 4. 段階（レベル）

媒質の向きは常に ±x, ±y のいずれか（4方向）。

| 段階 | 状況 | ねらい | 扱うつまずき |
|---|---|---|---|
| 1 | v₁ と v₂ が同一直線上（順流・逆流） | 速さの足し引き。逆流で v₁ < v₂ なら下流へ進む | M2 |
| 2 | v₁ ⊥ v₂（直交） | 向けた方向≠進む方向。渡る時間は流れに無関係 | M1, M3, M5 |
| 3 | v₁ が斜め（v₂ は軸方向のまま） | v₁ を成分に分けてから成分ごとに足す | M4 |
| 4 | 逆問題：目標地点に着くには v₁ をどちらへ向けるか | 合成速度の向きを先に決め、v₁ を逆算する | M1, M4 |

- 段階4は後回しのフェーズで実装する（[11_roadmap.md](11_roadmap.md)）。
- 段階1は相対速度アニメーターの「同一直線上の場合を先に見せる」方針と一致させる。

## 5. 授業での使い方（例：50分）

| 時間 | 活動 | モード |
|---|---|---|
| 0〜8分 | 教師が段階2の場面を提示し「どこに着く？」と全員に予想させ、再生して外させる | 探究（提示） |
| 8〜15分 | コマ送り再生で「1秒ごとの変位を足すと合成になる」を確認。②の作図手順を示す | 探究（提示） |
| 15〜35分 | 生徒が各自で段階1→2→3の練習問題を解く | 練習 |
| 35〜43分 | 流れなしの船との同時比較で「渡る時間は変わらない」を確認 | 探究（提示） |
| 43〜50分 | まとめ。到達した段階・正答数を確認 | — |

- 段階4は発展として、早く終わった生徒や次時に回す。
- 1問は2〜3分で終わる分量を目安にする。
