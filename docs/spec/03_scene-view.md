# 03 ① イメージ図

上から見た平面図（俯瞰2D）で、媒質と物体の運動を描く。

## 1. 構成要素

| 要素 | 内容 |
|---|---|
| 地面の目盛り | 1 m ごとの薄い格子、5 m ごとの濃い線。動かない。画面が細かくなりすぎるときは、線と数字を間引く（数字の間隔は 5・10・20・25・50 m から、重ならないものを選ぶ） |
| 媒質シート | 半透明の方眼シート。v₂ で平行移動し続ける（端は継ぎ目なくループ） |
| 浮遊物 | シート上に散らばる小さな印（落ち葉など、スキンによる）。シートと一緒に動く |
| 岸（川スキンのみ） | 流れの向きに平行な2本の線。物体は片方の岸から出発 |
| 物体 | 船など（スキンによる）。**船首は v₁ の向きを向く**。進む向き（v の向き）とは一致しない |
| 物体上の矢印 | 物体から v₁（青）・v₂（緑）・v（赤）を表示。表示のON/OFFを切り替えられる。**v₁ と v₂ の先端には丸いつまみがあり、ドラッグで変えられる**（v₂ は上下左右にだけ動く。v₂ = 0 のときはひし形のつまみを v₁ の横に置く）。v₁ と v₂ が同一直線上のとき、または v₂ = 0 で v と v₁ が重なるときは、v₂ と v を直線の両側へ少しずらして描く |
| 軌跡2本 | 媒質に対する軌跡（青点線、シートに貼り付いて流れる）と地面に対する軌跡（赤実線＋1秒ごとの点） |
| 予想マーカー | 生徒が置いた予想（×印、経路予想は灰色破線） |
| 目標マーカー | 段階4などで目標地点がある場合に表示 |

### 媒質に対する軌跡の描き方

物体の媒質に対する位置 r₁(t) = v₁t を、**シートの座標系で**記録して描く。シートが流れるので、この線も一緒に流れていく。生徒からは「水面に描いた線は、船が描いたとおりの真っすぐな線だが、水ごと流されている」ように見える。これが M2（何に対する速度か）への直接の手がかりになる。

## 2. 画面の範囲（縮尺）

- 問題ごとに範囲を自動で決める。地面に対する最終到達点と、出発時・終了時の速度の矢印の先が必ず画面内に収まるようにする。
- **範囲から答えが推測できないようにする**：流れに沿う方向は、出発点を中心に左右（上下）対称に広げる。広げる量は「流される距離＋余白」を 5 m 単位で切り上げた値とし、最小値を設ける。
- 流れと直交する方向は、岸の間（川幅）＋上下の余白。

## 3. 終了条件（問題の「目標」）

| 種類 | 終了のしかた | 使う段階 |
|---|---|---|
| 対岸到達 | 物体が向こう岸に達したら停止 | 2, 3, 4 |
| 時間指定 | 指定時間（例：5 s）経過で停止 | 1, 3 |
| 地点指定 | 目標地点に達したら停止（外れたら最接近時刻で停止し、ズレを表示） | 4 |

段階1（同一直線）は岸を渡らないので、「◯秒後にどこにいるか」の時間指定を基本にする。

- 時間指定では、出発点を**川の中央**に置く（岸は出発点から ±川幅/2）。指定時間より先に岸に達したら、そこで止める。
- 対岸到達で、合成速度に向こう岸へ向かう成分がない（負）ときは出発せず、その旨を表示する。
- **流れに沿う方向に出発点から 30 m 進んだら止める**（「画面の端まで来たので止めました」と表示）。v₁ を流れと平行にすると岸に着かないため、これがないと画面が際限なく広がる。
- 合成速度が 0 のときは 20 秒で打ち切る（水だけが流れ、船は地面に対して止まって見える）。

### 探究モードで選べる止め方

選択肢を減らすため、探究モードでは次の2つだけにする。川幅は 12 m に固定する。

| ボタン | 止め方 |
|---|---|
| 向こう岸で | 対岸到達 |
| 5秒で | 時間指定（5 s） |

## 4. 予想の入力

- **着地点予想（必須）**：① をタップすると × マーカーが置かれる。ドラッグで微調整。対岸到達の問題では岸の線上にスナップする。
- **経路予想（任意）**：設定でONにすると、物体から指でなぞった線が灰色破線で残る。
- 予想を置くまで練習モードの再生ボタンは押せない（「どこに着くか予想しよう」と表示）。

## 5. 比較表示：流れなしの物体

操作バーの「比較」をONにすると、同じ v₁ をもち **v₂ = 0** の物体（半透明）を同時に走らせる。

- 段階2で両方が**同時に対岸に着く**ことを見せる（M5）。
- 2つの物体を結ぶ線（流れ方向の差）を表示すると、「違うのは流れ方向の位置だけ」が分かりやすい。

## 6. 媒質視点（後回しのフェーズ）

カメラが媒質シートと一緒に動く表示に切り替える。このとき媒質は止まって見え、地面と岸が −v₂ で動いて見える。物体は v₁ で真っすぐ進む。相対速度アニメーターの視点切替と考え方をそろえる。

## 7. スキン

物理は同じで見た目だけを替える。「媒質」という抽象を掴ませるのが目的。

| スキン | 媒質 | 物体 | 岸 |
|---|---|---|---|
| 川と船（既定） | 水 | 船 | あり |
| 風と飛行機 | 空気 | 飛行機 | なし（地上の目標地点で代替） |
| 動く歩道と人 | 歩道の床 | 人 | 歩道の縁（流れに平行） |

スキンは後回しのフェーズで追加する。最初は川と船のみ。
