# 00 概要

## アプリ名（仮）

**合成速度ラボ**（リポジトリ名：`resultant_velocity`）

## 目的

高校物理基礎「速度の合成」で、生徒が次の3つを自分の操作を通して獲得することを目指す。

1. **向けた方向と進む方向は違う**（流れがあれば物体は流される）。
2. **「何に対する速度か」を区別できる**（媒質に対する速度／地面に対する速度）。
3. **ベクトルを足す理由がわかる**（1秒間の変位を足すことが、速度を足すことそのもの）。

あわせて、成分ごとに足せば合成速度が求まること、流れと直交する方向の運動は流れの影響を受けないこと（成分の独立性）を扱う。

## 対象

- 高校物理基礎の「速度の合成」の単元。
- 通信制・全日制のどちらでも、1回の授業（40〜50分）の中で使い切れる分量を基本とする。

## 使用場面（前提）

- **生徒が各自の端末で操作する**場面と、**教師がプロジェクタで提示する**場面の両方に対応する。
- 基準はタブレット横画面・PC。スマホ縦画面でも操作できるようにする（[02_screen-layout.md](02_screen-layout.md)）。
- ネットワーク接続は初回読み込みのみ。サーバーは使わず、学習記録は端末内に保存する。

## 中心となる考え方

3つの表現を対応させる。

| 窓 | 表現 | 役割 |
|---|---|---|
| ① 場面 | 媒質（流れる方眼シート）と物体の運動 | 予想を描く／結果を見る |
| ② ベクトル図 | 方眼上の矢印 | 合成を作図する |
| ③ 成分表 | vx, vy の数値 | 成分ごとの和を確かめる |

ただし、3つを常に自動で連動させると、表現の間の「翻訳」をアプリが代行してしまい生徒は眺めるだけになる。そこで、

- **探究モード**：自動連動。教師の提示や自由な試行に使う。
- **練習モード**：連動を切り、生徒が欠けた表現を自分で作る。答え合わせで初めて連動する。

の2つを用意する（[06_modes-and-sync.md](06_modes-and-sync.md)）。

## 原案からの主な変更点

原案：三窓（①媒質と物体、②ベクトル図、③成分入力）、①②は手書き、③に入力すると相互に対応、ボタンで再生、媒質はx・yの4方向のみ。

| 原案 | 本仕様 | 理由 |
|---|---|---|
| 手書きで矢印を描く | 方眼上で先端をドラッグし格子点にスナップ | 成分がマス目から読め③と自然につながる。判定ができる |
| 常に相互連動 | 探究モード（連動）／練習モード（非連動） | 翻訳を生徒にさせるため |
| 再生のみ | 予想→再生→照合。コマ送り再生を追加 | 予想とのズレが学習の起点。変位の足し算を見せる |
| 軌跡は1本 | 「媒質に対する軌跡」と「地面に対する軌跡」の2本 | 「何に対する速度か」を絵で分ける |
| 媒質は4方向のみ | **維持** | 流れが常に一つの成分だけになり、成分の考え方と一致する |

## 関連アプリ

- **相対速度アニメーター**（Shin-phys/Relative_speed_animator）：「流れの中の運動（観察版）」を扱う。本アプリはその先の、生徒が作図・予想する段階と、最短経路などの逆問題（段階4）を受け持つ。
- **落下比較アプリ**：水平投射と自由落下の同時着地。本アプリの「渡る時間は流れに関係ない」と同じ構造（成分の独立性）であり、授業でつなげられる。
