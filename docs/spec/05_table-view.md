# 05 ③ 成分表ビュー

## 1. 表の形

|  | vx [m/s] | vy [m/s] | 大きさ [m/s] |
|---|---|---|---|
| v₁（物体・媒質に対して） | □ | □ | （自動） |
| v₂（流れ） | □ | □ | （自動） |
| **v（合成・地面に対して）** | □ | □ | （自動） |

- 上2行と合成の行の間に「＋」と区切り線を入れ、**合成の行が上2行の和**であることを表の形で見せる（筆算の見た目）。
- 大きさの列は入力しない。成分から自動計算し、小数第1位で表示する。練習モードでは照合まで隠す。
- v₂ の行は、媒質が4方向のみなので、どちらか一方の成分は必ず 0 になる。

## 2. 入力

- 各セルは整数のみ（−20〜20）。符号の入力に配慮し、セルの横に「±」切替ボタンを置く（スマホのテンキーで負号が打ちにくいため）。
- 空欄は未入力として扱う（0 とは区別する）。
- 問題で与えられたセルは固定表示（灰色背景、編集不可）。

## 3. 成分の向きの補助

- 列見出しに「→ が正」「↑ が正」の小さな図を添える。
- 段階1（同一直線）では、関係する方向の列だけを強調し、もう一方の列は 0 固定で薄く表示する。

## 4. 合成の行を計算させるか

- 練習モードでは、v の行を生徒に入力させる問題（成分ごとの足し算を自分でさせる）と、v の行を自動で埋める問題の両方を用意する（問題データで指定）。
- 探究モードでは常に自動計算。
