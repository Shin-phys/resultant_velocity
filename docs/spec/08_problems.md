# 08 問題セット（練習モード）

## 1. 問題の型

どの型も、最初に ① で**予想**を置く（T4 のみ「向きの予想」）。

| 型 | 与える表現 | 作らせる表現 | ねらい |
|---|---|---|---|
| T1 数値→図 | ③ の v₁・v₂ の行 | ② の作図（v₁, v₂, v）、③ の v の行 | 数値を矢印に翻訳する |
| T2 図→数値 | ② の v₁・v₂（固定表示） | ② の v、③ のすべての行 | 矢印を成分に翻訳する |
| T3 場面→図・数値 | ① の場面（船首の向きと速さ、流れの向きと速さを文字で添える） | ② の作図、③ のすべての行 | 状況を読み取ってベクトルにする |
| T4 逆算 | v₂、v₁ の大きさ、目標地点 | v₁ の向き（②・③）、v | 合成の向きを先に決めて逆算する |

## 2. 段階と型の対応

| 段階 | 主な型 | 目標の種類 |
|---|---|---|
| 1 同一直線 | T3, T1 | 時間指定（例：5 s 後の位置） |
| 2 直交 | T3, T1, T2 | 対岸到達 |
| 3 斜め | T1, T2, T3 | 対岸到達 |
| 4 逆問題 | T4 | 地点指定（対岸の真向かい、または指定地点） |

## 3. 段階4の数値と補助

- ② の矢印は格子点にスナップするため、段階4は**正答の v₁ が格子点に乗る組（ピタゴラス数 3-4-5, 6-8-10, 5-12-13 など）**だけで作る。
- 補助表示「円のガイド」：v₂ の終点を中心に半径 |v₁| の円を薄く描く。原点から目標方向への半直線と円の交点が v の終点になる、という作図を視覚的に示す（ON/OFF可、既定OFF、ヒントボタンでON）。
- 最短距離で渡る問題（|v₁| < |v₂| で接線を引く作図）は、正答が格子点に乗らないため本アプリでは扱わない。

## 5. 類題の自動生成（やり直し用）

やり直しでは、元の問題から次のいずれかで類題を作る。

- **左右反転**：v₁, v₂, 目標地点の x 成分の符号を反転（流れが x 方向の場合）。
- **流れの向きの反転**：段階1・2で v₂ の符号を反転（段階1は v の符号が変わる場合も含めて有効）。
- 問題データに `variants` があればそちらを優先する。

類題も整数成分・格子点上の正答という条件を保つ。

## 6. 問題データの形式

問題は JSON ファイルで持ち、教師が追加・編集できるようにする（`src/data/problems/stage1.json` など）。

```json
{
  "id": "s2-01",
  "stage": 2,
  "type": "T3",
  "skin": "river",
  "v1": [0, 4],
  "v2": [3, 0],
  "goal": { "kind": "crossBank", "width": 12 },
  "askResultantRow": true,
  "gridRange": 8,
  "text": "船は静水に対して 4 m/s で対岸に船首を向けて進む。川は右向きに 3 m/s で流れている。船はどこに着くか。",
  "variants": []
}
```

| フィールド | 内容 |
|---|---|
| `type` | `T1`〜`T4` |
| `goal.kind` | `time`（`t` 秒）／`crossBank`（`width` m）／`point`（`target` [x, y]、`width` m） |
| `v1Speed` | T4 のみ。v₁ の大きさ（`v1` は正答として持つ） |
| `askResultantRow` | ③ の v の行を生徒に入力させるか |
| `gridRange` | ② の表示範囲（省略時 8） |
| `variants` | 類題の v1, v2, goal の配列（省略可） |

読み込み時に検証する：v₂ が軸方向であること、成分が整数であること、T4 で |v1| = v1Speed であること、目標の種類と段階の組み合わせが妥当であること。
