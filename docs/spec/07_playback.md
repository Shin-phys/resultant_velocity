# 07 再生とアニメーション

## 1. 連続再生

- 実時間（×1）を基本とし、×2 を選べる。
- 物体の位置：r(t) = (v₁ + v₂) t（出発点を原点として）。
- 媒質シート：オフセット v₂ t で平行移動。
- 地面に対する軌跡には **1秒ごとに点**（ストロボ）を打つ。点の間隔が |v| × 1 s になることが、② の v の長さと対応する。
- 終了条件（対岸到達・時間指定・地点指定）で自動停止する（[03_scene-view.md](03_scene-view.md)）。
- ⏸一時停止、⏮リセット（t = 0 に戻し軌跡を消す。予想マーカーは残す）。

## 2. コマ送り再生（変位の足し算を見せる）

「ベクトルを足す理由」（M3）を見せるための再生方法。1秒を1コマとし、1コマを2段階に分けて見せる。

| 段階 | 動き | 描くもの |
|---|---|---|
| (a) 物体が自分で進む | 媒質シートは止めたまま、物体だけが v₁ × 1 s 進む | 青い変位矢印（v₁Δt） |
| (b) 媒質が運ぶ | 物体は媒質に対して止まったまま、シートごと v₂ × 1 s 流れる | 緑の変位矢印（v₂Δt）。(a) の先端につながる |
| (c) 合成 | (a)(b) をつないだ始点から終点へ赤い矢印を引く | 赤い変位矢印（vΔt） |

- ⏭を押すたびに1コマ（(a)→(b)→(c)）進む。各段階の動きは 0.6 秒程度のアニメーション。
- 前のコマの矢印は残し、コマを重ねると青・緑の階段と赤の直線が並ぶ。「階段を何段のぼっても、赤い直線の上に乗っている」ことが見える。
- 同時に ② に「1秒あたりの変位＝速度」という一行の説明と、(a)(b)(c) と同じ順で v₁・v₂・v が描かれる様子を出す。
- 注記（教師向け・ヘルプ内）：実際の運動では (a)(b) は同時に起きている。コマ送りは2つを分けて見せるための表現であり、1コマを短くしても結果は変わらないことを、設定の「コマの長さ」（1 s / 0.5 s / 0.25 s）を切り替えて確かめられるようにする。

## 3. 比較表示（流れなしの物体）

- 連続再生・コマ送りのどちらでも使える。
- 流れなしの物体は半透明で、地面に対する軌跡も薄い色で描く。
- 対岸到達の問題では、2つの物体が同時に岸に着いた瞬間に一時停止し、「同時に着いた」と表示する（段階2・3）。

## 4. 速度ベクトルの表示（場面上）

- 物体上の矢印は、② の方眼と同じ縮尺ではなく、場面で見やすい長さに一定倍率で描く（例：1 m/s ＝ 場面の 1 m 相当）。倍率は問題ごとに固定し、途中で変えない。
- 再生中も矢印は物体と一緒に動く。
