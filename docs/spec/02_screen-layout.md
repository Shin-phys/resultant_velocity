# 02 画面構成

## 1. 全体構成

```
┌──────────────────────────────────────────────────────┐
│ ヘッダー：アプリ名｜モード切替（探究／練習）｜段階｜スキン｜設定 │
├───────────────────────────────┬──────────────────────┤
│                               │ ② ベクトル図           │
│ ① 場面                        │   （方眼・矢印）        │
│   （媒質シート・物体・軌跡）     ├──────────────────────┤
│                               │ ③ 成分表               │
│                               │   （v₁, v₂, v の vx/vy） │
├───────────────────────────────┴──────────────────────┤
│ 操作バー：▶再生 ⏸ ⏮リセット｜コマ送り ⏭｜速度×1/×2｜比較表示 │
├──────────────────────────────────────────────────────┤
│ 指示・フィードバック欄（練習モードの問題文、照合結果、問いかけ）   │
└──────────────────────────────────────────────────────┘
```

- ① が最も広い（横幅の約60%）。② と ③ は右側に縦に並べる。
- 指示・フィードバック欄は常に1〜3行。長文は出さない。

## 2. 画面サイズごとの配置

| 条件 | 配置 |
|---|---|
| 横幅 ≥ 900px（PC・タブレット横） | 上図のとおり。① 左、②③ 右に縦積み |
| 横幅 < 900px かつ縦長（スマホ縦・タブレット縦） | ① を上半分に固定。下半分を **②／③ のタブ切替** にする |
| 提示モード（設定でON） | 文字・矢印・線を1.5倍。操作バーを大きく。フィードバック欄を非表示 |

- スマホ縦でタブ切替にしたとき、片方のタブで変更が起きたら（探究モードの連動など）、もう一方のタブ見出しに小さな印を付けて気づかせる。

## 3. 色と記号の約束（全窓共通）

3つの速度は、どの窓でも同じ色・同じ線種で描く。窓をまたいで同じものだと分かるようにするのが目的。

| 量 | 色（仮） | 線 | 備考 |
|---|---|---|---|
| v₁（媒質に対する物体の速度） | 青 | 実線矢印 | |
| v₂（媒質の速度） | 緑 | 実線矢印 | 媒質シートの浮遊物も緑系 |
| v（合成速度） | 赤 | 太線矢印 | |
| 予想 | 灰 | 破線・×マーカー | |
| 媒質に対する軌跡 | 青 | 細い点線 | シートと一緒に流れる |
| 地面に対する軌跡 | 赤 | 細い実線＋1秒ごとの点（ストロボ） | |

- 色だけに頼らず、矢印の脇に必ず記号（v₁, v₂, v）を添える（色覚の多様性への配慮）。
- ダークモードでも判別できる配色にする。

## 4. 操作の基本

- タッチ・マウスの両方で同じ操作ができること。
- ドラッグ操作は格子点にスナップする。スナップ時に軽く強調表示する。
- 誤操作の取り消し：② と ③ はそれぞれ「1つ戻す」ボタンを持つ。
